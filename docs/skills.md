# Skills et bonnes pratiques

Inventaire consulté le 9 octobre 2026 : catalogue des skills de la session, dossiers `~/.codex/skills`, `~/.agents` et cache des plugins. Aucun skill Impeccable, Vercel React Best Practices ou Web Design Guidelines n’est présent dans ces emplacements.

Les instructions du skill système `skill-installer/SKILL.md` ont été lues. Aucun skill externe non vérifié n’a été téléchargé. La demande concerne en priorité les skills déjà disponibles; installer un dépôt tiers non fourni ajouterait des instructions non examinées au projet. Les skills de documents, images et sites ne sont pas nécessaires pour initialiser cette application Next.js existante.

Les bonnes pratiques React/Next.js sont appliquées directement et documentées : Server Components par défaut, frontières client limitées à l’interactivité, logique métier dans `src/server`, dépendances minimales, données serveur faisant autorité et structure accessible. Les composants UI suivent l’installation manuelle et la variante Radix de shadcn/ui.

Références officielles consultées : [React Server Components](https://react.dev/reference/rsc/server-components), [React `use client`](https://react.dev/reference/rsc/use-client), [Next.js Server et Client Components](https://nextjs.org/docs/app/getting-started/server-and-client-components), [shadcn/ui installation manuelle](https://ui.shadcn.com/docs/installation/manual), [shadcn/ui Button Radix](https://ui.shadcn.com/docs/components/radix/button).

Une installation future d’Impeccable ou d’un skill Vercel nécessite une source officielle identifiée, une lecture des instructions et de ses scripts, puis une installation via `skill-installer`. Leur absence ne bloque pas les fondations et ne signifie pas qu’ils ont été installés.
