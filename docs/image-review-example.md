# Exemple de dossier de revue : Lewis Hamilton

Le [dossier JSON](image-review-example.json) propose une référence Wikimedia Commons pour Lewis Hamilton, identifiant TheSportsDB `34157136`. Le 12 octobre 2026, une requête de métadonnées à l’[API officielle Commons](https://commons.wikimedia.org/w/api.php?action=query&format=json&prop=imageinfo%7Crevisions&titles=File%3ALewis+Hamilton+during+the+2025+Belgian+Grand+Prix+weekend.jpg&iiprop=url%7Cextmetadata%7Ctimestamp%7Csha1&rvprop=ids%7Ctimestamp) a retourné l’auteur **Skyebble**, la licence **CC BY 4.0**, l’attribution obligatoire, l’URL du fichier original et les références de révision. La [page du fichier](https://commons.wikimedia.org/wiki/File:Lewis_Hamilton_during_the_2025_Belgian_Grand_Prix_weekend.jpg) est la preuve consultable ; la révision et le SHA-1 sont conservés dans le dossier.

La licence [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) permet les réutilisations sous ses conditions, dont l’attribution, le lien de licence et l’indication des modifications. La mention de licence ne garantit pas les droits à l’image de la personne, les marques ni une autorisation d’associer la photographie à un produit commercial ou à une présentation suggérant un soutien de l’athlète.

**Ce dossier reste non approuvé.** Le fichier image n’a été ni téléchargé ni affiché ; ses métadonnées ont été enregistrées dans la base locale comme dossier non approuvé, sans confirmer les droits d’usage. La description API associe la photographie à Lewis Hamilton au Grand Prix de Belgique 2025 ; son cadrage et son adéquation comme portrait n’ont pas été vérifiés. Un administrateur doit examiner le visuel exact, la cohérence de l’identité, les droits complémentaires et l’attribution prévue avant toute activation.

Le JSON est un dossier documentaire, pas un payload à envoyer directement à une route d’approbation : il comprend des preuves et des champs techniques supplémentaires. Adapter seulement les champs autorisés après la revue. Conserver le fallback pendant cette étape. Une absence de texte dans `Restrictions` ne vaut pas validation générale.

Méthode reproductible : `action=query`, `prop=imageinfo|revisions`, `iiprop=url|extmetadata|timestamp|sha1` et `rvprop=ids|timestamp` dans l’[API Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo). Les métadonnées HTML de l’auteur ont été converties en texte et en URL de référence ; aucun HTML provenant de Commons n’est destiné à être injecté dans l’interface.
